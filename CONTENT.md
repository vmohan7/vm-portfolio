## Adding an item

Before publishing, record:

1. exact public title and canonical URL
2. Vasanth’s precise role: author, speaker, panelist, host, interviewer, producer, or another confirmed credit
3. public date only when verified by the source body or first-party event material
4. image source and permission or license
5. a concise description that does not import unsupported performance, audience, award, or achievement claims

For videos, use the platform’s official preview only as a linked video thumbnail. Do not treat it as a gallery photograph or evidence of a production credit.

For gallery images, add optimized originals under `assets/gallery/`, write useful alt text, and include a short caption and source/permission note here.

## Editing conventions

- keep the type and spacing restrained, with separate pages rather than an all-in-one scrolling presentation
- bump the shared stylesheet query version across all five pages when changing CSS, and update the matching static check, so returning visitors do not keep stale styles
- newest verified work appears first
- recent work remains in the main sequence; older highlights move to a clearly labeled archive
- visible link text should describe the destination
- external links open in a new tab and include `rel="noopener noreferrer"`
- every copy change should preserve valid heading order and plain-language link labels
- run `python3 tests/check_navigation.py`, `python3 tests/check_static.py`, `node --check script.js`, and `node tests/check_copy.js` after edits
